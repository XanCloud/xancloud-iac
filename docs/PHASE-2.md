# Capacidades privadas (consultoría)

Estas capacidades existen como extensiones privadas para clientes de consultoría.
No forman parte del repositorio abierto.

## Extensiones disponibles

- **CI/CD**: GitHub Actions para `tofu fmt`, `tofu validate`, y `tofu plan` en PR.
- **Policy scanning**: Checkov ≥ 3.2.x y OPA/Rego para reglas de seguridad.
- **Testing**: `tofu test` y Terratest para integración.
- **Docs automáticas**: terraform-docs en pre-commit; README generados por módulo.
- **Multi-account**: AWS Organizations, SSO (IAM Identity Center).
- **Security services**: GuardDuty, SecurityHub, AWS Config.
